# 采购、销售与资金核对记录

参考前端的收付款入口包括 `/v1/bill/receipt/create/frombill`、`/v1/bill/payment/create/frombill` 和两类 `query/list/frombill`。资料还列有作废接口、账户和结算字段。可确认原页面把业务单据与收付款单关联，原服务端的分录和核销算法仍无源码可验证。依据见 `zhjspace/docs/附录-接口目录.json` 与后端逻辑说明第 2 节资金单据部分。

| 检查项 | 禾序现状与验证 |
|---|---|
| 从业务单发起收付款 | 销售详情进入收款，进货详情进入付款。原收款路由缺失模式参数的问题已修复。来源单据预填本次待核销余额。 |
| 组合账户 | 结算单支持多账户，每笔资金分录与总额按分校验。分录和核销同事务写入。测试模拟第二笔分录失败，单据、资金分录和核销全部回滚。 |
| 分次与逐单核销 | 新建核销关联表。校验单据类型、往来单位、业务日期、同单重复与剩余金额。挂账退货扣减原单待核销余额，实际现金退款通过资金流水抵消其影响。 |
| 对账口径 | 一张 100 元销售单收款 60 元，55 元分配到单据。单据待核销 45 元，往来净余额 40 元，差额 5 元为尚未分配的款项。历史未关联收付款仍体现在往来汇总。 |
| 凭证 | 收付款详情和 A4 凭证显示账户分录与核销来源。回归验证供应商取名、金额和 HTML 转义。 |
| 角色范围 | 核销读写使用资金单据权限，综合单据查询、详情和打印按具体业务权限检查。销售和采购接口拒绝伪造的跨域单据类型。 |

本轮尚未补齐历史未分配款项的补核销、销售或采购过账时直接结算、订金抵扣、坏账核销和资金红冲。订单分批出入库、期初欠款逐单化和账龄历史查询仍是独立待核项。

桌面冒烟使用临时账套验证 10 元销售、两账户共收 4 元、核销 3 元。销售详情进入收款界面后，待核销金额正确预填 7 元。
