> **什么是局域网协作？** 多台电脑（一台"主机"+ 多台"客户端"）在同一门店局域网内共用一套账：主机保管数据库，客户端开单、查库存、收款，数据实时汇总到主机。全程走门店内网，不连外网、不上传第三方服务器。

# 第 1 节 主机端：开启局域网协作与配对

> 前提条件：① 主机电脑持有**专业版授权**（含"局域网协作"功能）；**7 天全功能试用期内无需激活码即可体验本功能，试用到期转只读并关闭 LAN 协作**；② 主机与客户端在同一局域网；③ 电脑防火墙允许本软件使用 **18650 端口**（见第 3 节）。

## 1.1 开启 LAN 协作

1. 以管理员账号登录主机电脑上的禾序进销存。
2. 进入 `系统与数据 → 设置 → 局域网协作`。
3. 将"启用局域网协作主机"开关打开，软件会提示**需要重启**——重启后主机开始监听（端口 18650），系统托盘区出现应用图标，悬停可见"主机状态：运行中 (18650)"。

![局域网协作设置页](screenshots/lan-settings.png)

> 注意：标准版授权看不到此开关（属专业版功能）。开关只在**专业授权 + 手动开启**两者同时满足时才生效，不满足时软件与 v1.2 完全一致，不加载任何网络组件。

## 1.2 生成配对码（二维码/输码）

1. 客户端发起连接请求后，主机端会弹出**配对确认卡片**（主窗口顶部，无需点开设置页）。
2. 卡片显示：设备名称、配对码（6 位数字）、剩余有效期。
3. 也可以主动查看待确认列表：`设置 → 局域网协作 → 待配对设备`。

## 1.3 允许 / 拒绝配对

1. 确认卡片上的设备名称与您手上那台电脑一致后，点 **[允许]**——该设备立即收到连接密钥，完成配对。
2. 点 **[拒绝]** 或不理会：配对码 5 分钟后自动作废，客户端需重新发起。
3. 配对码**一次性使用**：一台设备用掉后即失效，不会泄露给第二台。

## 1.4 设备管理（查看与吊销）

1. `设置 → 局域网协作 → 已连接设备`：列出所有已配对设备（名称、最近连接时间）。
2. 点击某设备的 **[吊销]**：该设备立即被踢下线，密钥作废，再次使用需重新配对。适合设备转卖、员工离职等场景。

# 第 2 节 客户端：连接与日常操作（v1.4 已实现）

> v1.3 时客户端侧为"规划中"；**v1.4.0 起客户端接线已完整落地**：本机作为客户端时，业务
> 请求经 `lan:invoke` 转发到主机执行、数据只落主机库，客户端不会把单据写进本机库造成数据分叉。
> 客户端入口在 `系统与数据 → 客户端连接`（菜单项"客户端连接"）。

## 2.1 配对连接（首次）

1. 客户端电脑安装并启动禾序进销存（版本需与主机一致或更高）。
2. 进入 `系统与数据 → 客户端连接`，填写：
   - **主机地址**：如 `192.168.1.10:18650`（页面会给出建议格式）；
   - **本机设备名**：如"前台收银机"，主机端据此辨认是哪台设备；
   - **主机账号 / 主机密码**：主机上已有的员工账号（密码），用于建立会话。
3. 点击 **[申请配对]**：客户端向主机 `/pair/start` 发起请求并自动轮询配对结果，页面进入
   "等待主机确认配对"状态并显示 6 位配对码与倒计时。
4. 主机端在「设备配对」里确认本设备、点 **[允许]**；客户端自动收到密钥、证书指纹，
   建立会话并切换到"**已连接**"，可正常登录员工账号开始操作。
5. 若主机点 **[拒绝]** 或超过有效期未处理：配对码作废，重新 **[申请配对]** 即可。
   （配对码由主机下发、一次性使用；主机端二维码供扫码录入地址，不替代账号密码。）

> 客户端本机**也需具备 LAN 协作权限**：7 天全功能试用期内自动放行；试用到期（只读）会
> 拒绝连接；正式使用需在本机激活专业版授权（按机授权口径，见第 3.5 节待裁决说明）。

## 2.2 日常操作范围与断线禁写

- 已连接时可用的功能与主机一致（按各自账号权限）：开销售单/零售、查库存、录采购等；
  所有单据数据实时保存在**主机**上，主机端和其它客户端的列表会实时刷新。
- **客户端不能执行主机专属操作**（备份/云同步等），此类操作请在主机上完成；客户端误落到
  本机 handler 的请求会被明确拒绝（`E_CLIENT_MODE`），防止数据写错库。
- 顶部 `ConnectionStatusBar` 显示连接状态；**一旦不是"已连接"（断线 / 连接中 / 出错 /
  被吊销），零售收款与销售单保存按钮被禁用并给出提示**，避免离线期间产生无法提交的写操作。
  恢复连接后按钮自动恢复。单机模式（未配置主机）完全不受此限制。
- 断线期间发起的幂等写请求会进入本机"待重发"队列（按 requestId 去重），主机恢复、
  重连成功后自动重发且**只生效一次**；退出软件前也会 flush 一次待重发队列。

## 2.3 断线重连与吊销

- 客户端与主机短暂断开（如网线松动）：顶部出现断线提示条，主机恢复后自动重连，
  **无需重新配对**（凭据经 Windows DPAPI 加密保存在本机，重启软件自动恢复）。
- 主机管理员在「已连接设备」里 **[吊销]** 本设备：客户端立即被踢下线、密钥作废，状态变为
  "**已被吊销**"，页面给出醒目提示与重新申请配对的表单；旧会话无法再登录。
- 主机关机或长时间不可达：显示断线提示条，写操作在主机不可达期间暂停，查询仍可用；
  主机恢复后自动重连。
- 页面提供 **[断开连接]**（保留配对信息，可随时 **[重连主机]**）与 **[忘记主机]**
  （清除本机凭据，回到未配置状态）。

## 2.4 连接状态一览

| 状态 | 页面提示 | 可否开单/收款 |
|---|---|---|
| `connected`（已连接） | 顶部绿标"已连接" | 可 |
| `pairing`（等待确认） | 显示配对码+倒计时 | 否 |
| `connecting`（连接中） | "正在连接主机…" | 否 |
| `revoked`（已被吊销） | 红色"本机已被主机吊销，需重新配对" | 否 |
| `error` / `idle` | 显示错误或连接表单 | 否（单机模式除外） |

# 第 3 节 安全与故障排查

## 3.1 安全机制一览

| 机制 | 说明 |
|---|---|
| 配对码一次性 | 6 位数字，5 分钟有效，仅可使用一次；每 IP 每分钟最多发起 10 次 |
| 密钥不落地明文 | 配对成功下发的密钥经 Windows 加密存储（DPAPI），仅本机可解 |
| 通信加密 | 全部走 HTTPS/WSS（主机自签证书）；配对完成后业务调用与事件通道会核对主机证书指纹 |
| 请求防伪造 | 每个请求带时间戳（±2 分钟内有效）与一次性随机数，重放无效 |
| 吊销即时生效 | 主机吊销设备后该设备立即断开且无法再登录 |
| 权限沿用账号 | 客户端操作权限由登录的员工账号决定，与单机版一致 |

> **安全边界（如实披露）**：本版本适用于 3 台以内设备、彼此可信的小局域网。
> 配对阶段（`/pair/start` 与 `/pair/result`）与登录（`/auth/session`）采用首次信任（TOFU），
> 尚无证书鉴证；配对完成后的业务通道虽核对证书指纹，但比对发生在响应回调，
> 即请求体已经发出之后。**能在配对窗口内主动实施 ARP 欺骗或架设恶意热点的攻击者**
> 可冒充主机、读到配对窗口内的账号口令与设备密钥。普通嗅探/改 UI 无法绕过。
> 「握手期先验指纹再发送」的彻底加固已列入 v1.4.1 专项，不在本版范围。

## 3.2 常见错误与处理

| 错误提示 | 原因 | 处理 |
|---|---|---|
| `E_PAIRING_DENIED`（配对被拒绝）/ `E_PAIRING_EXPIRED`（配对码过期） | 主机端点了拒绝 / 5 分钟内未完成确认 | 与店长确认后重新发起配对 |
| `status: "denied"`（/pair/result 轮询返回"已拒绝"） | 主机端点了拒绝 | 与店长确认后重新配对 |
| `E_HOST_ONLY`（仅主机可用） | 操作了仅限主机执行的功能（如恢复备份、同步） | 换到主机电脑上操作 |
| `NOT_ENOUGH`（库存不足） | 并发开单时最后一件被别人先卖出 | 正常现象；单据会明确提示商品与剩余数量，修改数量重试 |
| `E_AUTH_FAILED`（登录失败） | 账号密码错误 / 设备被吊销 | 核对账号密码，或重新申请配对 |
| `E_SESSION_EXPIRED`（会话已过期） | 8 小时会话到期或 token 失效 | 在「客户端连接」页点「重连主机」，重新输入主机账号密码即可，无需店长重新确认配对 |
| `E_FEATURE_PRO`（专业版专属） | 当前授权（基础版 / 试用到期只读 / 旧授权码）无该功能；7 天试用期内全功能，不触发本错误 | 升级为专业版授权后使用（多仓、序列号/批次效期、员工账号 RBAC）；试用期内无需升级 |
| `E_DEVICE_LIMIT`（设备数达上限） | LAN 协作接入设备数已达授权上限 `maxDevices`（基础版缺省 1 台） | 吊销不用的设备后再配对，或升级授权提高上限 |
| 连接不上主机 | 主机未开启 / 防火墙拦截 / 不在同一网段 | 见 3.3 |

## 3.3 防火墙与端口

1. 主机首次开启 LAN 协作时，Windows 防火墙若弹窗询问，请点 **[允许访问]**（勾选"专用网络"）。
2. 未弹窗但客户端连不上时，手动放行：`控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 18650 → 允许连接`。
3. 端口固定为 **18650**，不可更改；主机电脑建议设置固定内网 IP（DHCP 保留），避免 IP 变动导致客户端连不上。

## 3.4 其他注意事项

- **数据备份照旧**：LAN 模式下数据库仍只存在主机上，请继续按 v1.1 手册第 10 章在主机上做加密备份（v1.3 支持口令加密 INVBAK）。
- **不要两台都当主机**：只有持有专业授权并开启开关的电脑才是主机；客户端无需开启该开关。
- **时间要准**：各电脑系统时间相差不能超过 2 分钟（建议开启 Windows 自动时间同步），否则请求会被拒绝。
