> **什么是局域网协作？** 多台电脑（一台"主机"+ 多台"客户端"）在同一门店局域网内共用一套账：主机保管数据库，客户端开单、查库存、收款，数据实时汇总到主机。全程走门店内网，不连外网、不上传第三方服务器。

# 第 1 节 主机端：开启局域网协作与配对

> 前提条件：① 主机电脑持有**专业版授权**（含"局域网协作"功能）；② 主机与客户端在同一局域网；③ 电脑防火墙允许本软件使用 **18650 端口**（见第 3 节）。

## 1.1 开启 LAN 协作

1. 以管理员账号登录主机电脑上的禾序进销存。
2. 进入 `系统与数据 → 设置 → 局域网协作`。
3. 将"启用局域网协作主机"开关打开，软件会提示**需要重启**——重启后主机开始监听（端口 18650），系统托盘区出现应用图标，悬停可见"主机状态：运行中 (18650)"。

![局域网协作设置页](screenshots/lan-settings.png)

> 注意：标准版授权看不到此开关（属专业版功能）。开关只在**专业授权 + 手动开启**两者同时满足时才生效，不满足时软件与 v1.2 完全一致，不加载任何网络组件。

## 1.2 生成配对码（二维码/输码）

1. 客户端发起连接请求后，主机端会弹出**配对确认卡片**（主窗口顶部，无需点开设置页）。
2. 卡片显示：设备名称、配对码（6 位数字）、剩余有效期。
3. 也可以主动查看待确认列表：`设置 → 局域网协作 → 待配对设备`。

## 1.3 允许 / 拒绝配对

1. 确认卡片上的设备名称与您手上那台电脑一致后，点 **[允许]**——该设备立即收到连接密钥，完成配对。
2. 点 **[拒绝]** 或不理会：配对码 5 分钟后自动作废，客户端需重新发起。
3. 配对码**一次性使用**：一台设备用掉后即失效，不会泄露给第二台。

## 1.4 设备管理（查看与吊销）

1. `设置 → 局域网协作 → 已连接设备`：列出所有已配对设备（名称、最近连接时间）。
2. 点击某设备的 **[吊销]**：该设备立即被踢下线，密钥作废，再次使用需重新配对。适合设备转卖、员工离职等场景。

# 第 2 节 客户端：连接与日常操作

## 2.1 配对连接（首次）

1. 客户端电脑安装并启动禾序进销存（版本需与主机一致或更高）。
2. 进入 `系统与数据 → 设置 → 局域网协作 → 连接主机`，输入主机显示的 6 位配对码（或扫描主机二维码）。
3. 等待主机端点击 [允许]——成功后客户端显示"已连接"，可以正常登录员工账号开始操作。

## 2.2 日常操作范围

- 客户端登录后可用的功能与主机一致（按各自账号权限）：开销售单/零售、查库存、录采购等。
- 所有单据数据实时保存在**主机**上；主机端和其它客户端的列表会实时刷新（新单据出现、库存变化无需手动刷新）。

## 2.3 断线重连行为

- 客户端与主机短暂断开（如网线松动）：顶部出现黄色"重连中…"提示条，恢复后自动重连，无需重新配对。
- 主机关机或长时间不可达：提示条变红"门店主机不可用，单据提交已停用"，开单/写操作按钮停用（防止数据丢失），查询本地缓存仍可用；主机恢复后自动重连。
- 主机端正常退出软件前，建议先通知客户端保存工作；主机退出后客户端处于上述"不可达"状态。

# 第 3 节 安全与故障排查

## 3.1 安全机制一览

| 机制 | 说明 |
|---|---|
| 配对码一次性 | 6 位数字，5 分钟有效，仅可使用一次；每 IP 每分钟最多发起 10 次 |
| 密钥不落地明文 | 配对成功下发的密钥经 Windows 加密存储（DPAPI），仅本机可解 |
| 通信加密 | 全部走 HTTPS（自签证书 + 证书指纹校验），防嗅探防篡改 |
| 请求防伪造 | 每个请求带时间戳（±2 分钟内有效）与一次性随机数，重放无效 |
| 吊销即时生效 | 主机吊销设备后该设备立即断开且无法再登录 |
| 权限沿用账号 | 客户端操作权限由登录的员工账号决定，与单机版一致 |

## 3.2 常见错误与处理

| 错误提示 | 原因 | 处理 |
|---|---|---|
| `E_PAIRING_INVALID`（配对码无效） | 码输错 / 已过期 / 已被使用 | 在主机重新发起配对，5 分钟内输入 |
| `status: "denied"`（/pair/result 轮询返回"已拒绝"） | 主机端点了拒绝 | 与店长确认后重新配对 |
| `E_HOST_ONLY`（仅主机可用） | 操作了仅限主机执行的功能（如恢复备份、同步） | 换到主机电脑上操作 |
| `NOT_ENOUGH`（库存不足） | 并发开单时最后一件被别人先卖出 | 正常现象；单据会明确提示商品与剩余数量，修改数量重试 |
| `E_AUTH_FAILED`（登录失败） | 设备被吊销 / 会话过期 | 重新配对或重新登录 |
| 连接不上主机 | 主机未开启 / 防火墙拦截 / 不在同一网段 | 见 3.3 |

## 3.3 防火墙与端口

1. 主机首次开启 LAN 协作时，Windows 防火墙若弹窗询问，请点 **[允许访问]**（勾选"专用网络"）。
2. 未弹窗但客户端连不上时，手动放行：`控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 18650 → 允许连接`。
3. 端口固定为 **18650**，不可更改；主机电脑建议设置固定内网 IP（DHCP 保留），避免 IP 变动导致客户端连不上。

## 3.4 其他注意事项

- **数据备份照旧**：LAN 模式下数据库仍只存在主机上，请继续按 v1.1 手册第 10 章在主机上做加密备份（v1.3 支持口令加密 INVBAK）。
- **不要两台都当主机**：只有持有专业授权并开启开关的电脑才是主机；客户端无需开启该开关。
- **时间要准**：各电脑系统时间相差不能超过 2 分钟（建议开启 Windows 自动时间同步），否则请求会被拒绝。
