# P4 平台与发布验收

核对范围包括实施计划 P4、原始设计 §5，以及恢复前端资料中的平台入口。参考前端用于确认功能和交互边界，禾序的 Electron、SQLite 和 IPC 实现独立编写。

## 实施计划核对

| 任务 | 当前行为与证据 | 验收边界 |
| --- | --- | --- |
| T1 手动备份与恢复 | `backup.service` 通过 SQLite 生成一致性副本。用户确认后先校验快照、保留原账套，再在关闭数据库后重启并替换。可从备份列表或文件选择器恢复。保留本机授权、同步配置和恢复操作记录。 | 定向用例覆盖 WAL、重复命名、无效库拒绝和恢复前副本。 |
| T2 云盘同步 | 本地目录和 WebDAV 可并用。上传压缩 `.zjsnap`，附版本、时间、设备、序号和 SHA-256。上传前留本地副本，远端序号领先时阻止覆盖并提示。支持定时上传、上次成功和失败状态、旧 `.db` 回读。 | 测试覆盖本地快照往返、竞争序号和本地 HTTP WebDAV；真实服务商凭据及跨设备同步需实机验收。本地目录仅能确认文件写入。 |
| T3 新手引导 | 保留欢迎向导，首次进入主要业务模块时显示上下文导览。关闭或完成后记录模块，欢迎向导的跳过继续关闭后续提示。 | 当前导览面向管理员，使用本机浏览器存储记录模块完成情况。 |
| T4 操作员和角色 | 管理员和收银员使用 scrypt 密码验证和主进程权限校验。首次使用设置管理员密码；旧默认密码禁止登录并引导重设。设置页可查询最近操作记录。 | P4 的内置角色已实现。角色自定义、可选 PIN 和免登录是后续差异，恢复资料中存在自定义角色入口。 |
| T5 试用与激活 | 首启生成安装 ID，7 天全功能试用（含专业版功能）、无延期、到期只读，时钟回退消耗三次宽限。使用 Ed25519 验签和有效期校验，在线兑换码绑定本机设备。独立签发服务以 SQLite 保存兑换码哈希和绑定，支持授权解绑。 | 本地验证兑换、重试、拒绝异机和解绑后换机。正式公钥与 HTTPS 服务地址尚待发行方配置，旧仓库私钥已移除并需更换。 |
| T6 更新提示 | 登录进入工作台后及持续运行期间定期检查。仅当配置了 HTTPS 更新地址时请求，用户点击后用系统浏览器打开已验证的下载地址。 | 单测覆盖正常版本比较、无网络和不安全下载地址。正式更新地址尚未提供。 |
| T7 自动备份 | 采用原始设计 §5.4 的每日首启和最近 30 份规则。恢复前副本单独保留。 | 定向测试验证同日只生成一次，并按备份名称的日期保留最新版本。 |
| T8 Windows 发行 | 本地安装包、安装冒烟与发行配置由主工程验收。 | 网站发布、HTTPS 服务与生产签名属于发行配置和部署。 |

## 恢复前端与其他设计材料

恢复前端 `renderer-web/web/js/corp.d855235c.js` 包含操作记录入口。功能地图 §3.9 和接口附录还确认了操作员列表、角色列表及权限配置入口。原服务端权限和审计的存储规则无法由前端确认，禾序以本机权限表和操作记录独立实现。企业注册、多租户、门店、收银机和提成在原始设计中排除。

产品 PRD 和《离线进销存技术实现与离线售卖激活》定义了更广的单机发行方案，包括独立设备存储、离线申请和签名许可文件、备份可选加密、版本化多目的地、恢复为新账套，以及授权异常仍可只读、备份和完整导出。这些条款与本次 Electron P4 存在差异，需单独验收。当前离线凭证通过文本录入，恢复经确认后替换单账套，快照可校验，默认数据库与备份不加密。
