# P3 报表、打印和数据交换审计

范围以 `../docs/superpowers/plans/2026-11-07-p3-reports-print-excel.md` 的 T1–T7 为基准，并对照产品设计 §2.2、§6 及参考前端可观察的行为。参考材料位于同级 `zhjspace` 目录。报表在本地 SQLite 查询真实业务数据，设备和文件操作走 Electron IPC。

| 计划项 | 本地实现与验证 | 剩余边界 |
|---|---|---|
| T1 经营仪表盘 | `dashboard.service.ts` 汇总今日销售、零售、销售单数、收付款、存货金额、预警商品和往来余额。销售毛利使用对应出库流水成本。七日趋势用日期区间补零和 CSS 柱图。历史成本、库存预警及日期边界由 `dashboard.service.test.ts` 覆盖。 | 首页销售和零售分别展示，销售单毛利保持 P3 销售单口径。经营报表另外提供包含零售与销售退货的净额口径。 |
| T2 打印数据 | `print.service.ts` 装配单号、日期、往来方、仓库、商品规格、单位、数量、金额与店铺设置。调拨单显示调入仓库，盘点单显示账面、实盘和带方向的差异。`print.service.test.ts` 覆盖设置、商品规格、HTML 转义和盘点数据。 | 历史单据按当前商品名称与规格出纸。原单没有保存的商品描述快照无法恢复。 |
| T3 热敏小票 | 依据 P3 定案走系统打印驱动，支持 58/80 mm 模板、可配置抬头和尾注。`print.ipc.test.ts` 模拟 Chromium 打印回调，验证设备失败回传及隐藏窗释放。 | 真机纸张裁切、驱动默认介质、离线队列行为需要 Windows 热敏机验收。产品设计中提到的 Win32 原始 ESC/POS 和打印设备绑定仍是差异。 |
| T4 A4 PDF | 采购、销售、调拨、盘点及部分退货和组装单据使用独立 HTML 模板，隐藏窗生成 A4 PDF 后弹出保存对话框。单据查询中心可触发。 | A4 模板支持固定版式。参考前端的字段拖放、按单据和纸型管理多套模板、纸张预览及打印设备绑定仍是差异。 |
| T5 Excel 兼容导出 | 使用 P3 定案的 UTF-8 BOM CSV。商品、客户、供应商、库存、采购和销售单据明细及经营报表在对应页面有导出入口。多单位单据按单据计量单位导出数量和单价。报表导出完整筛选结果。 | 原生 XLSX 和往来方完整账簿迁移未覆盖。批量单位、条码、图片与复杂商品属性的无损往返不在当前商品 CSV 模板内。 |
| T6 商品与期初库存导入 | 商品表可下载模板、按编码新增或更新，并返回行号及校验错误。期初表可选择仓库、下载模板、载入和审核行，再通过一次性期初事务保存。服务测试覆盖无效价格与追踪值、零数量、行级错误与预览不写库。 | 接收固定列顺序的 CSV。参考前端的电子表格列映射、分步骤工作台、多属性批量更新未覆盖。 |
| T7 单据查询 | 按类型、日期、单号、往来名称或编码查找，详情只读。客户与供应商按业务类型关联，防止主键相同造成错配。`doc.service.test.ts` 包含同编号回归。 | 查询中心使用单据头与明细，并保留业务页入口。业务工作流和收支、订单等扩展单据见相应模块审计。 |

## 参考前端和后端推断

参考 `zhjspace/docs/09-完整功能地图（真实前端）.md` §3.7、§3.14，`10-后端逻辑说明（前端反推）.md` 的商品导入、报表与对账、打印设置章节，以及 `11-离线还原说明与覆盖清单.md`。`renderer-web/mock/columns.json` 将报表路由映射到 `report-statistic.e1b53ae2.js`。该前端的可观察输入包含 `start_date`、`end_date`、往来单位、账户、商品编码和商品名称。共享 chunk 中的参数和接口存在跨页复用，无法仅从同一 chunk 推定每页全部契约。

| 参考行为 | 目前还原的本地语义及差异 |
|---|---|
| `/report/sale-statistics`、`/report/purchase-statistics` 和各自 `/detail` | 销售和采购按日期聚合单量、原额、退货额及净额，支持日期和仓库。销售统计包含零售。按往来、商品或操作员等多维切换和统计行钻取仍待补齐。 |
| `/report/profit-list`、`/report/profit-detail`、库存损耗明细 | 经营毛利按对应单据的历史成本流水计算，日聚合缺少成本时显示空值。盘盈盘亏从实际过账流水重建。独立利润明细和非库存经营费用并入口径仍待补齐。 |
| `/report/fund-list` 的流水列表和独立图表 | 提供账户、日期、收入/支出、单号或备注筛选，以及整个筛选区间的收支总额。旧版退货产生的无真实账户占位流水不参与统计。分类占比图及参考前端的操作员、单据类型组合维度仍待补齐。 |
| `/report/hot-sale`、`/report/stock-check` | 热销按商品基准单位统计净销量、按数量排名，支持仓库和商品关键字。库存盘点表提供各仓库和批次当前账面量，已入账盘盈亏单列。参考接口的库存数量、价格视图及扩展商品分类仍有差异。 |
| `/report/receivable-list`、`/report/payable-list` 及各自明细 | 已有往来余额表和期初、交易、结算金额。分日期区间重建期初与往来逐笔对账及钻取尚缺。 |
| `/report/serial-number` 与 `sn/query/stock/list`、`sn/query/flow/list` | 仍缺。当前商品可标记序列号追踪类型，但没有在过账时采集每件序列号和流向。此处需要真实库存事件及序列唯一性约束。 |
| `/setting/print-template/list`、`/print/editor`、打印设备关系及字段预设接口 | 本地配置支持抬头、尾注和 58/80 mm 宽度，输出 A4 或系统驱动打印。可复用模板的创建、编辑、删除、复制、预设重置及设备关系需要独立实现。 |

`renderer-web/mock/data.mjs` 对热销、资金流水列表和图表、进货统计及库存数量和价格端点有独立规则，也对许多报表及导入导出接口使用通用示例规则。`docs/12-离线mock使用说明.md` 记载了打印设备限制。Mock 用于确认界面请求和响应形状，金额公式、数据持久化和硬件效果通过本地实现与测试确认。
